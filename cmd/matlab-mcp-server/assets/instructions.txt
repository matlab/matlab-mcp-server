This server provides tools to inspect, analyze, run, and test MATLAB code using a locally installed MATLAB instance.

Available tools:

- List installed MATLAB toolboxes and versions.
- Statically analyze a MATLAB .m script.
- Execute inline MATLAB commands.
- Execute a MATLAB script file (.m or .p).
- Run a MATLAB test script.

Available resources:

- guidelines://coding. Provides comprehensive MATLAB coding standards for improving code readability, maintainability, and collaboration. The guidelines encompass naming conventions, formatting, commenting, performance optimization, and error handling.
- guidelines://plain-text-live-code. Provides rules and guidelines for generating MATLAB Live Scripts using plain text Live Code .m format, suitable for version control and AI-assisted development. Requires MATLAB R2025a or newer.

Best practices and safety:

- Always inspect tool outputs and catch errors. If execution fails, ask the user for clarification.
- Do not run untrusted code that could alter the file system or environment settings, without explicit consent from the user.
- Do not use commands that reset MATLAB's search path (e.g. `restoredefaultpath`) as they remove the MCP server functions from the path and permanently break communication with the MATLAB session.
